## How it works
Label: How it works
Headline: Three steps to Arabic you don't have to fix.
Lede: Dualkit plugs into the agent you already use, loads when a task touches Arabic, and checks the result before a user sees it.
01 Install the skills. One command adds four skills to Claude Code or Cursor. There is nothing to configure.
02 Build as usual. Ask for the screen you need. The skills load on their own and handle direction, digits and type.
03 Check before you ship. Run npx dualkit check. It scores the page against 20 rules and shows every failure next to its fix.

## The kit
Label: The kit
Headline: Five parts, each installed on its own.
Lede: Start with the skills, then add formats, components and checks when you need them.
01 Skills. Teach your agent Arabic. Four skills for Claude Code and Cursor: right-to-left layout, type pairing, Gulf formats and bilingual copy.
 - Load on their own when a task touches Arabic
 - Took a fresh agent from 0 of 3 to 3 of 3 on bidi bugs
 - Listed in the Claude plugin directory
02 Format. Money, dates, phones and IBANs, parsed from the digits people type, Arabic or Latin.
03 Starter. Eight bilingual components you copy into your app.
04 Check. Run one command and get a report of every rule your page breaks, with the fix beside it.
05 Bench. A monthly score of how well free AI models build Arabic.
